# 本地测试 Web 服务只读诊断

目标固定为 `http://test-web/health`，不需要 SSH 或主机登录信息。

1. 保存只读诊断计划，说明检查范围仅为 HTTP 可达性。
2. 调用 `probe_test_web(url="http://test-web/health")` 获取真实证据。
3. HTTP 200 仅表示健康接口可正常响应；非 200 按实际状态码描述。
4. 连接失败或超时只能说明当前不可访问，不能直接推断容器已停止、数据库故障或网络根因。
5. 调用 `submit_diagnosis_result`，在结论中引用实际返回的目标、时间、状态码或错误。

禁止调用 Shell、SSH、审批或修复工具。禁止重启服务、修改配置、使用模拟拓扑补充结论。
没有工具结果时明确标记证据不足。工具失败也应保留失败证据，不得假设服务恢复。
